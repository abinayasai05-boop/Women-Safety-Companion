Women Safety Companion

Overview

Women Safety Companion is a simple frontend website designed to promote personal safety awareness. It provides quick access to emergency information and safety-related features.

Live webpage https://abinayasai05-boop.github.io/Women-Safety-Companion/

Features

- SOS Alert section
- Live Location feature card
- Emergency Contacts
- Safe Routes information
- Emergency Helpline Numbers
- Responsive and user-friendly design

Technologies Used

- HTML5
- CSS3

Project Structure

- "index.html" – Main webpage
- "style.css" – Styling and layout

How to Run

1. Download the project files.
2. Open the project folder.
3. Double-click "index.html" or open it in any web browser.

Future Enhancements

- Real-time location sharing
- One-click SOS messaging
- Nearby police station locator
- Emergency contact management
